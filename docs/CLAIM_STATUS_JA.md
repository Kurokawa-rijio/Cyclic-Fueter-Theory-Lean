# 命題群 α — 53項目(α-I〜VIII)と α-IX 35 項目の現行判定

**基準日：2026-11-02(v0.3.0)**

この一覧は研究の進捗管理用であり、第三者による査読済み判定ではない。Leanで形式化された定理の仮定・結論と、物理的な主張全体の強さは区別する。

- **完**：作者の台帳で完全と評価（外部定理を使うものを含む）
- **完(外)**：明示された外部定理を仮定した範囲で完全
- **部**：形式化が主張より弱い
- **条**：核心の仮定または外部入力が残る
- **未**：未形式化、または台帳と形式化対象が一致しない

集計(α-I〜VIII):**完（完(外)を含む）41 / 部7 / 条2 / 未3 = 53**

集計(α 全体、α-IX を含む):**完 51 / 部 7 / 条 2 / 未 3 / 未着手 25 = 88**
