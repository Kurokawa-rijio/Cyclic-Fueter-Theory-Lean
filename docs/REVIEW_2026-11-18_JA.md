## 2. 仮定で特に確認してほしいところ

1. **`C2Data`・`C2On`**(CharUniqueness、WedgeUniqueness):
   - 長方形の辺の点でも両側の `HasDerivAt` を仮定しています。つまり、解が長方形より少し外まで C¹ で延びている前提です。
   - 方程式とデータは長方形の上だけに課しています(`WedgeEqsOn`、`WedgeDataOn`)。ただし上の両側微分の仮定があるので、「仮定はすべて長方形の上だけ」とは言えません。
2. **`goursat_exists`**:
   - F は大域的にリプシッツであると仮定しています。くさびの系に使うときは、右辺を切り落としてから(`trunc`)当てはめています。
   - データは ℝ 全体で微分可能で、導関数が連続であることを仮定しています。
2b. **`wedge_dependence`(4-8)**:
   - 「データの差」は辺の上の C¹ トレースの差です(v = 0 の辺で値と ∂_u、u = 0 の辺で ∂_v)。
   - 定数 C は B、m、a、b で決まります。B、m は解に課す評価なので、C は解の評価を通して解に依存します(評価を固定した族の中での連続依存)。
3. **`wedge_local_existence`**:
   - ε は存在を言うだけで、具体的な値は出していません。
   - 作った解が拘束 C_u、C_v をみたすことは、まだ示していません。4-9 の「解」も `wedge_local_wellposed` の一意性も、発展方程式だけについての主張です。
4. **導分代数のモジュール**(Mechanics、Continuum、LinGrav、Geodesic):
   - 連鎖律(`hg`、Kepler の `dri`)、定数の微分が 0 であること(`hk`、`hμ` など)、偏微分が可換であること(`hc`)は、仮定として外から入れています。
   - 実際の関数がこれらの仮定をみたすことは、別に示す必要があります(Schwarz の橋渡しは未着手)。
5. **`contracted_bianchi_normal`**:
   - 正規座標の点 p(Γ(p) = 0、∂g(p) = 0)での式(∂Ric、∂R、∇^a G_ad)を、定義 `dRic`・`divG` にそのまま書き込んでいます。
   - 定義が正しい式になっているかを、点検の対象にしてください。
   - テンソル性の段(正規座標で 0 なら任意の座標で 0)は形式化していません。
6. **Kepler**:
   - 平面運動で質量は 1、力は −k r/|r|³ としています。
   - ri = 1/r は (x² + y²) ri² = 1 で与え、`dri` は仮定として入れています。
7. **Bernoulli**:
   - ρ は定数で、定常性は Euler 方程式に ∂_t の項を入れないことで表しています。
   - 渦なしは j = 1, 2, 3 だけで仮定します(今回、j = 0 まで含んでいた余分な仮定を外しました)。
8. **Coulomb**:
   - ∂_j x_j = 1(対角だけ)と、∂_j ri = −x_j ri³ を仮定しています。
   - (独立点検で追記)この 2 つの仮定は `∀ j : Fin 4` で、時間の添字 j = 0 も含みます。静的なポテンシャル(∂₀ ri = 0)では
     j = 0 の `hri` から x₀ = 0 が出て、j = 0 の `hx`(∂₀ x₀ = 1)と矛盾します。`coulomb_harmonic`・`coulomb_fueter` は、
     ∂₀ = ∂_t のふつうのモデルには当てはめられません。直し方は仮定を j ≠ 0 に制限することです(定理の文の変更なので未実施)。
9. **EM 不変量**:
   - `SpecialRel` では x 方向のブーストだけを扱っています。
   - 一般の場合は `FueterBridge.em_square_invariant`(F ↦ qFq⁻¹)で示しましたが、「Lorentz 変換が双四元数の共役で書ける」ことの形式化は既存の極分解(`LorentzPolarDecomposition`)と照合が必要です。
10. **四元数の力学(QuaternionMechanics)**:
    - `attitude_unit` は 2q̇ = qω(ω は純虚)を仮定しています。
    - `frame_geodesic_speed` は接続を so(4) ≅ su(2) ⊕ su(2) の元(P, Q 純虚)として与えています。Levi-Civita 接続がこの形になることは仮定です。
11. **Cartan–Einstein(CartanEinstein)**:
    - 一階形式です。曲率 R は接続から作られて枠 e によらないとし、e だけを変分しています。
    - 4 次元 Euclid の正規直交枠で、R には 2 組の反対称性だけを仮定しています(対称性 R_abcd = R_cdab や第 1 Bianchi は不要)。
    - 接続の変分から捩れ 0 が出ること、Lorentz 符号への移行、座標との対応は CartanTorsionLorentz で示しました(下の 11b)。
11b. **捩れ・Lorentz・座標(CartanTorsionLorentz)**:
    - `Ktor` は接続 ω の Euler–Lagrange の式を**部分積分した後の標準形**を、枠 e = δ の点で定義として書き込んだものです。部分積分そのものは形式化していません。定義が正しい式かを点検してください。
    - 捩れ T は後ろ 2 添字の反対称性だけを仮定しています。
    - `levi_civita_unique` は C_abc(枠の非可換性)を与えられたものとし、両立性 ω_abc = −ω_bac と捩れ 0 の式から Koszul の式を出すだけです(任意の添字集合 ι)。
    - Lorentz 版は、R の 2 つの添字を η で上げた R̃ = ηηR を Euclid 版にそのまま入れて示しています。`eps_raise`(ε の 4 添字を上げると −1 倍)が鍵です。
    - 座標との対応は `curv_gauge_covariant`(一般の非可換環)で、曲率が枠の行列 g で共役に移ることまでです。g⁻¹ の微分 ∂g⁻¹ = −g⁻¹(∂g)g⁻¹ は `dAprime` の定義に書き込んであり、∂∂g の対称性 `hsym` と g g⁻¹ = 1 を仮定しています(g⁻¹ g = 1 は使っていません)。
    - 「Christoffel の行列を枠に移したものが Levi-Civita の ω」であることと、縮約(Ric、R)が枠と座標で一致することは形式化していません。
    - 物質の項は Σ k_{aμ} T_{μa} の形で直接与えています(8G = T の係数は作用の規格化 Σ ε ε e e R による)。
11c. **4-17(WedgeLocalExistenceGeneral)**:
    - データ φ、ψ は C¹(`ContDiff ℝ 1`)で、角で一致し、角で r > 0、Ω > 0 とだけ仮定しています。
    - 角は (0,0) です。一般の角 (u₀,v₀) は平行移動で移りますが、形式化していません。
    - 一意性のために `WedgeUniqueness` に `SameDataOn` 版を足し、もとの `wedge_uniqueness`、`wedge_uniqueness_of_pos` はその系に書き直しました(文は同じ)。
    - 拘束 C_u、C_v は含みません。
    - データは ℝ 全体で C¹ です。辺の上だけのデータを ℝ に延ばす補題は入れていません。
    - ε は存在するだけで明示していません。r₀(角での r、Ω の小さいほうの半分)は明示的です。
    - (独立点検で追記)「C² 解」の C² は `C2On`(値・∂_u・∂_v・∂_u∂_v が連続)の意味で、∂_u²、∂_v² は含みません。
      データが C¹ だけなので、解の r_uu(v = 0 の辺では φ₀″)は一般には存在しません。拘束 C_u、C_v を扱うには、
      データを C² 以上にして解の 2 階微分の存在を示す段が先に要ります。
    - `wedge_uniqueness_of_pos` は定理の文は同じですが、docstring を 1 か所書き換えました(「長方形の外については何も仮定しない」→「方程式は長方形の外に課さない」)。
    - Muse の `WedgeC1Contraction` は縮小の評価までで、Banach の不動点定理の適用はしていません。存在の証明として引用するのはこのモジュール(`WedgeLocalExistenceGeneral`)です。
11d. **枠 ↔ 座標(FrameCoordinateEinstein)**:
    - 枠の曲率 `RF` は、座標の Riemann テンソル Rc(添字はすべて下)を枠 E で移したものとして定義しています。
    - Rc の 2 組の反対称性は仮定です。Christoffel から作った Riemann(`CurvatureJetAlgebra.riem`)の添字を下げたものがこれをみたすことは示していません。
    - 枠の完全性は Σ_μ e^a_μ E_b^μ = δ_ab の片側だけを仮定し、もう片側は `Matrix.mul_eq_one_comm` で出しています。

    - `einstein_lorentz_coord` の `V`、`Rt` は `CFT.CartanEinstein` のものです。
    - 縮約は 2 番目と 4 番目の添字で取っています(`CartanTorsionLorentz.RicL` と同じ)。
12. **Maxwell の双四元数形**:
    - 単位は c = ε₀ = μ₀ = 1 です。

## 3. 記号・規約(混ざりやすいところ)

- **Riemann:** R^a_bcd = ∂_c Γ^a_db − ∂_d Γ^a_cb + Γ^a_ce Γ^e_db − Γ^a_de Γ^e_cb(`riemann Γ dΓ a b c d`)。dΓ c a d b = ∂_c Γ^a_db。
- **Ricci:** R_bd = R^a_bad。正規座標版の `dRic b a d` は ∂_b Ric_ad。
- **計量の微分:** jet は `dg c a b` = ∂_c g_ab、`ddg e c a b` = ∂_e∂_c g_ab。正規座標版は `H x y u v w` = ∂_u∂_v∂_w g_xy。
- **□ の符号:** LinGrav は η = diag(−1, 1, 1, 1) で □ = η^ρσ ∂_ρ∂_σ(= −∂₀² + Δ)。Fueter 側の `Box` は ∂₀² − Δ で、符号が逆です(`box_bridge`:box = −Box のスカラー部)。
- **くさびの右辺:** `rhsR`・`rhsOm`・`rhsW` は WedgeEYMSystem の定義(ℓ = 1)。Ω の式の r_uv は r の式で置き換えています(`eOm`)。
- **添字:** Fin 3 の 0 = r、1 = Ω、2 = W(WedgeExistence の `phiW`・`psiW`・`toPt`)。
- **空間の和:** `ssum` は j = 1, 2, 3(Fin 4 の 0 は時間)。
