# 古典物理を Lean で積み上げる計画(非線形 Einstein 方程式まで)

作成日:2026-11-18。置き場所は `CFT/Classical/`。

## 方針

- **書き方**:座標成分で書く(ℝⁿ 上の関数として、計量・接続・曲率の成分を扱う)。計算が軽い所では、座標によらない形(多様体の上)も並べて書く。
- **「完璧」の基準**
  - `sorry` がない。
  - 標準の公理(propext, Classical.choice, Quot.sound)しか使わない。
  - 微分は実関数の `HasDerivAt` / `HasFDerivAt` で書く。微分の値を記号として扱う段(jet)では、実関数への橋渡しを必ず別の定理で示す。
  - 外部の定理を仮定に置く場合は、定理の名前と文献を明記する。ただし非線形 Einstein 方程式の存在と一意性は、外部の定理に頼らず自前で示すことを目標にする(第 8 段)。
- **既存の資産**:球対称の場合(EYM、Schwarzschild、Reissner–Nordström、接合条件、拘束条件の伝播など)はすでにリポジトリにある。これらは一般の場合の特別な例として、新しい定理から導き直す。

## 第 8 段の道筋(自分の幾何学で証明する)

Einstein 方程式を、2×2 複素行列(SL(2,ℂ) のスピノル、つまり複素化した四元数)で書くと、1 階の対称双曲型方程式系になる(Friedrich のスピノル形式と同じ方向)。D̄D = Δ の因数分解と同じく、2 階の波動方程式を 1 階の Dirac 型の方程式の組に分けるのが鍵になる。

1. **エネルギー恒等式**:1 階の対称双曲型方程式系 A⁰∂_t u + Aⁱ∂_i u = B u について、∂_t(uᵀA⁰u) + ∂_i(uᵀAⁱu) = (下位の項)を示す。代数で閉じる。
2. **エネルギー不等式**:周期的な空間(トーラス)の上で積分し、Grönwall の不等式で E(t) ≤ e^{Ct} E(0) を示す。
3. **一意性**:2 つの解の差にエネルギー不等式を当てると差はゼロ。存在より先に一意性が示せる。
4. **線形の存在**:係数が滑らかな線形系の解の存在。Galerkin 近似か Picard 反復を使う。
5. **準線形の局所存在**:線形の解を反復して収束させる。Sobolev 空間の評価が必要で、一番重い段。
6. **Einstein 方程式への適用**:スピノル形式の Einstein 方程式が対称双曲型であることを示し、1〜5 を当てる。拘束条件が保存されること(第 7 段)と合わせて、Einstein 方程式の局所的な解の存在と一意性になる。

1〜3 は現実的な目標。4〜5 は Mathlib に足りない道具(Sobolev 空間、関数空間での反復)を自分で作る必要があり、長い道のりになる。
