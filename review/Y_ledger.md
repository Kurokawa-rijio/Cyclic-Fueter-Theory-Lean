# 1. Yから生み出された主要な式

## 第I群：Cyclic Fueter 幾何から量子状態の幾何へ

この系列では、あなたの研究に固有の幾何学的構成が最もよく現れています。

### Y1〜Y2：Fueter 作用素と階数・核の構造

基本となる右 Fueter 作用素は

\\[ D_R=\partial_0+i\partial_1+j\partial_2+k\partial_3 \\]

です。研究記録では、実四元数上のユークリッド的な作用素と、複素化した作用素、ローレンツ的な作用素を区別して扱っています。

例えば、ユークリッド的な実四元数の規約では、

\\[ \overline D_R D_R=\Delta_4 \\]

となります。一方、ローレンツ的なダランベルシアンを扱う際には、実四元数の式をそのまま流用せず、複素化・計量の規約を明示する必要があります。

さらに、係数行列 \\(C\\) の階数と核を

\\[ \operatorname{rank}\_{\mathbb H}C=3, \qquad \ker_R C=\gamma(-k)\mathbb H \\]

という形で整理しています。

状態：Y1は規約を固定した結果、Y2は階数・核構造が確立したと整理されています。ただし、左核ベクトルは係数を作用させる規約によって符号の照合が残っています。

数学的意味： 作用素の特異性を単に計算するのではなく、その核を後のスピノル・状態空間の構成に接続する出発点です。

物理的意味： この段階だけで粒子や質量ギャップを導くわけではありません。後の状態幾何を組み立てるための代数的な基盤です。

この部分の新規性は、四元数や Fueter 作用素自体ではなく、あなたの巡回的な階数・核構造を、後続の幾何学にどのように接続しているかにあります。

### Y3〜Y4：量子計量と量子球面

研究記録で重要な式は、

\\[ \boxed{g^Q=\frac12|dQ|^2} \\]

および状態空間の幾何学的同一視

\\[ \boxed{ (\mathbb R^3,g^Q)\cong S^3\_{1/\sqrt2,+} } \\]

です。ここで \\(S^3\_{1/\sqrt2,+}\\) は、半径 \\(1/\sqrt2\\) の三次元球面の開半球を表します。

この同一視を通じて、正エネルギー射影から定まる状態の幾何、Berry 接続、スピン状態の構造を同じ幾何学的枠組みで扱おうとしています。

数学的意味： 状態や射影の変化から自然に誘導される計量を、具体的な球面幾何として表現することです。抽象的な状態空間を、明示的な距離・曲率・接続を持つ空間へ落とし込んでいます。

物理的意味： 量子状態がパラメータ空間上を変化したとき、その変化を計量と接続で測れるということです。ただし、この球面は物理的な空間そのものではありません。Yang–Mills の配置空間や時空と直接同一視してはいけません。

新規性の評価： 量子計量、状態空間の球面幾何、Dirac 型系の Berry 幾何には先行研究があります。したがって、計量公式単独を新発見とするより、Cyclic Fueter の階数・核構造からこの特定の球面幾何をどこまで必然的に導いたかが、新規性の中心になります。

### Y5：Berry 接続と Wigner 接続

研究記録では、同じ運動量空間上の2つの接続について、

\\[ \boxed{ A_B=-\frac{m}{E}A_W } \\]

という関係を得ています。さらに、接続の係数が運動量に依存するため、単純な定数倍やゲージ同値として扱えないことを確認しています。

ただし、曲率 \\(F_B,F_W\\) の関係は、接続の関係から自動的には導けません。一般には \\(A_B=fA_W\\) なら、

\\[ F_B=df\wedge A_W +f\\,dA_W +f^2A_W\wedge A_W \\]

となります。したがって、記録されている

\\[ E^2F_B=-m^2F_W \\]

という曲率の式は、接続のスケーリングとは独立に、完全な曲率計算で成立することを確かめておく必要があります。

数学的意味： 2つの接続の差は単なる表記上の違いではなく、曲率やホロノミーを含む幾何学的な違いになり得ます。

物理的意味： 運動量空間で粒子のスピン状態を輸送するとき、Berry 接続と Wigner 接続は異なる役割を持ちます。両者の関係は、状態空間と相対論的スピン輸送のつなぎ方を調べるうえで重要です。

状態：接続の関係は研究記録上で確立。曲率の関係式は上記の微分項を含め、最終稿で再照合すべき項目です。

# 3. Y11〜Y15：格子 Yang–Mills の数学的基盤

### Y11〜Y12：リンク幾何と Hamiltonian

SU(2) 格子理論の配置空間は

\\[ \boxed{ \mathcal A\_\Lambda =SU(2)^{E} \cong(S^3)^{|E|} } \\]

です。リンクの幾何は、採用する計量の正規化によって半径、Ricci 曲率、ラプラシアンの固有値が変わるため、Y11 では3つの計量規約を区別しています。

Y12 の Hamiltonian は

\\[ aH\_\Lambda =\frac{x}{8}\sum\_\ell(-\Delta\_\ell) +\frac2x\sum_P V_P, \qquad V_P=1-\frac12\operatorname{tr}U_P \\]

です。強結合展開のために定数項を分離すると、

\\[ \widetilde H\_\Lambda =K-8z\sum_P\chi_P, \qquad z=x^{-2}, \qquad K=\sum\_\ell(-\Delta\_\ell) \\]

という形を使用しています。

数学的意味： 無限次元の場の理論に進む前に、有限次元のコンパクト配置空間上で Hamiltonian とスペクトルを明確に定義しています。

物理的意味： 電場項と磁場・プラケット項の競合を表します。

新規性の評価： SU(2) リンク球面、Kogut–Susskind Hamiltonian、プラケット作用そのものは標準的な格子ゲージ理論の構造です。独自性は、複数の幾何学的計量を混同せず、あなたの Fueter 幾何との比較に使える規約へ統一している点にあります。格子 Hamiltonian の基本構成は Kogut と Susskind に遡ります。

### Y13〜Y14：ゲージ商空間と関数不等式

ゲージ軌道で割った配置空間では、水平・垂直方向の分解が重要になります。研究記録では、形式的な商空間曲率を

と記述しています。これは、ゲージ方向を射影除去するための逆作用素を通じて、軌道空間の幾何を表す式です。

## Y16：Riccati 再帰と真空波動関数

\\[ \widetilde H\_\Lambda=K-8z\sum_P\chi_P, \qquad \Psi=e^R, \qquad R=\sum\_{n\ge1}z^nF_n \\]

と置き、固有値方程式を変形すると、

\\[ \boxed{ KR-\sum\_\ell|\nabla\_\ell R|^2 -8z\sum_P\chi_P=E } \\]

という非線形方程式を得ます。

係数を比較して、

\\[ \boxed{F_1=\frac23\sum_P\chi_P} \\]

さらに \\(n\ge2\\) では、

\\[ \boxed{ F_n=K\_\perp^{-1} \left(Q_n-\langle Q_n\rangle\right) } \\]

\\[ Q_n=\sum\_{r=1}^{n-1} \sum\_\ell \langle\nabla\_\ell F_r,\nabla\_\ell F\_{n-r}\rangle \\]

となります。\\(K\_\perp^{-1}\\) は定数関数を除いた部分への逆作用素です。

これは、基底状態の波動関数を直接解く代わりに、その対数 \\(R=\log\Psi\\) の係数を順次決定する方法です。

二次係数は、

\\[ \boxed{ \begin{aligned} F_2={}&-\frac1{18}\sum_P(\chi_P^2-1)\\\ &+\sum\_{P\sim Q} \left[ \frac{32}{351}\chi\_{\mathrm{rect}(P,Q)} -\frac4{117}\chi_P\chi_Q \right]. \end{aligned} } \\]

この係数は、Rayleigh–Schrödinger 摂動論と Riccati 再帰の二つの経路から一致すると報告されています。

数学的意味： 非線形固有値問題を、低次の係数だけで次の次数が決まる再帰問題へ置き換えています。

物理的意味： 真空波動関数に、単一プラケットの寄与、隣接プラケット間の相関、長方形ループの寄与がどのように現れるかを読み取れます。

新規性の評価： 対数波動関数の Riccati 変換や強結合展開は標準的な技法です。実際、格子ゲージ理論の質量ギャップに対する強結合展開は1981年の論文でも複数の時空次元について計算されています。

## Y17〜Y19：Hessian と Bakry–Émery 曲率

Y17 ではループ指標の微分を制御する補題を整え、Y18・Y19 ではそれらを真空測度の Hessian と Bakry–Émery 曲率の下界へ接続しています。

Y18 の一次打ち切り測度では、

\\[ \boxed{x>\sqrt{\frac{32}{3}}\simeq3.266} \\]

で正の下界が得られます。二次打ち切りでは、報告上の厳密な Hessian 評価を使用して \\(x>3.593\\) という閾値が得られています。

数学的意味： Hessian の負の寄与を上から抑え、\\(\operatorname{Ric}+\operatorname{Hess}W\\) が正になる領域を特定することです。

物理的意味： 真空測度の揺らぎが十分強く抑えられるならば、Poincaré 不等式などを通して、対応する Hamiltonian のスペクトルギャップを制御できる可能性があります。

ここで重要なのは、一次・二次の打ち切り測度に対する結論と、真の真空 \\(\Psi_0\\) に対する結論は異なることです。現時点では、後者への移行が未解決です。

## Y20：全次数クラスター評価

現時点で、Y20 はあなたの研究の中で最も重要な未解決課題です。

有限パッチ \\(S\\) の上で再帰を解いた係数を \\(F^S\\) とすると、連結成分を

\\[ \boxed{ \Phi_X = \sum\_{S\subseteq X} (-1)^{|X\setminus S|}F^S } \\]

という Möbius 反転で抽出する構成を採用しています。

これが厳密に成立すれば、固定したクラスター \\(X\\) の係数を有限パッチだけで求められ、格子の総体積に依存しない形へ整理できます。

さらに、共有リンクを持つ二プラケット系では、厳密な再帰から高次の係数を計算し、Y16 の二次公式と一致することが確認されています。直近の報告では20次まで延長し、全パッチの Hessian を考慮した有限次数の評価も進めています。

ただし、20次までの有限計算から \\(n\to\infty\\) の収束半径が厳密に決まるわけではありません。報告された \\(x\simeq3.650\\) は、20次より先も観測された増大率が続くと仮定した数値的な見積もりです。

Y20 の本当の目標は、

\\[ \boxed{ A_n= \sup\_\ell\sum\_{C\ni\ell} \\|\nabla^2\Phi_C^{(n)}\\|\_\infty \le C_0K_0^{n-1} } \\]

を、格子体積に依存しない定数 \\(C_0,K_0\\) で証明することです。

数学的意味： 局所的な係数計算を、全クラスターの総和に対する一様な評価に引き上げます。

物理的意味： 近似した真空波動関数ではなく、真の真空に対して Hessian の下界を導くための橋渡しになります。

新規性の評価： Möbius 反転やクラスター展開自体は既存の数学的手法ですが、Cyclic Fueter を含む格子模型の真空再帰に適用し、明示定数つきの Hessian 評価まで閉じられれば、具体的な技術的成果となり得ます。

なお、Shen・Zhu・Zhu は強結合の格子 Yang–Mills について、無限体積での Poincaré 不等式、Log-Sobolev 不等式、正の質量ギャップを証明しています。したがって、Y20 で独自に示すべきなのは「強結合でギャップがある」という定性的事実だけではありません。

# 5. Y26〜Y32：これから独自性を示すべき中核
